# 구현예정

추가하거나 수정해야 할 내용을 적는다. 상황을 보고 구현할 내용은 `docs/검토사항.md` 에 적는다.

## admin 인증

- admin API 인증 로직을 추가해야 한다
- `infra/caddy/Caddyfile` 이 `{$DOMAIN}/api/*` 와 `api.{$DOMAIN}` 도 api 로 연결해서, 사용자용 도메인에서도 `/api/admin/*` 를 호출할 수 있다

## 브랜치와 CI/CD

- `develop` 브랜치를 개발환경 브랜치로 쓴다
- CI/CD 는 `main`, `develop` 브랜치에서만 돌고 그 외 브랜치에서는 돌지 않게 한다. 지금은 `ci.yml` 이 `main` push 와 모든 pull request 에서, `deploy.yml` 이 `main` push 에서 돈다

## 식당 등록 화면

- 등록 폼, 등록 폼 상태의 지도, 테스트가 남아 있다. 정한 내용은 `docs/식당등록화면-남은작업.md` 에 적어 두었다
