# 음식점 데이터 남은 작업

2026-10-02 dev DB 에 음식점을 넣으면서 논의했지만 아직 작업하지 않은 내용을 적는다.

## 저장 API

- 음식점을 저장하는 API 가 없어서 검색 API 결과를 보고 SQL INSERT 로 dev DB 에 직접 넣었다
- 저장 API(`POST /api/admin/restaurants`)는 [음식점 검색 502](음식점-검색-502.md) 의 수정 방향과 함께 만든다
- 검색 응답에는 categories 가 없다. 지금까지는 카카오 `category_name`(예: `음식점 > 한식 > 육류,고기`)을 보고 사람이 골랐다

## dev DB 데이터

- 넣은 음식점 41곳은 레포에 기록되지 않는다. 새 DB 를 만들면 `db:migrate` 로 테이블만 생기고 데이터는 다시 넣어야 한다
- 데이터를 레포에 남기려면 seed 스크립트를 따로 만든다
- `description`, `thumbnail_url` 은 비어 있고 `restaurant_business_hours` 에는 영업시간을 넣지 않았다
- 바다김밥 2곳은 `korean` 으로 들어가 있다. `bunsik` 으로 바꿀지 정하지 않았다
