# 우분투 노트북 작업 정리

맥북에서 main 에 push 한 내용을 우분투에 받고 로컬 DB 에 마이그레이션을 적용한다.
명령은 모두 저장소 루트(`food-map/`)에서 실행한다.

## 1. main 받기

main 을 한 번 force push 했다(좌표 조회 API 커밋 `e83b3da` 를 히스토리에서 지우고 다시 커밋함). 우분투에서 2026-09-30 이전에 main 을 pull 했다면 `git pull` 이 충돌하므로 아래 순서로 맞춘다. 이 파일도 이 과정을 거쳐야 받을 수 있다.

```bash
git status                  # 커밋하지 않은 작업이 있는지 먼저 확인
git fetch origin
git log --oneline -3 origin/main   # 맨 위에 docs : 우분투 작업 정리 문서 추가 가 보이면 된다
git reset --hard origin/main
```

- `git status` 에 커밋하지 않은 작업이 있으면 `reset --hard` 전에 따로 백업한다.
- 우분투에서 `b130301` 이후 main 을 pull 한 적이 없으면 `git pull` 로 받아도 된다.

## 2. 의존성 다시 설치

`.npmrc`(hoisted 설치)를 지워서 pnpm 설치 방식이 바뀌었다.

```bash
pnpm install
```

- `The modules directory ... will be removed and reinstalled from scratch. Proceed?` 가 나오면 `Y` 를 입력한다.

## 3. .env 에 API 키 넣기

루트 `.env` 는 git 에 없어서 맥북에서 값을 옮겨 적어야 한다. 아래 세 줄을 채운다. api 는 시작할 때 세 값이 없으면 환경변수 검증에서 실패하고 종료된다.

```
KAKAO_REST_API_KEY=
JUSO_SEARCH_API_KEY=
JUSO_COORD_API_KEY=
```

## 4. 로컬 DB 띄우기

```bash
pnpm db:up
docker ps          # food-map-postgres 가 healthy 인지 확인
```

## 5. 기존 테이블 확인

예전에 `db:push` 로 테이블을 만들었다면 마이그레이션이 같은 테이블을 다시 만들다 실패한다. 먼저 확인한다.

```bash
docker exec food-map-postgres psql -U foodmap -d foodmap -c '\dt'
```

1. `restaurants` 가 없으면 6번으로 넘어간다.
2. `restaurants` 가 있으면 데이터 건수를 확인한다.
   ```bash
   docker exec food-map-postgres psql -U foodmap -d foodmap -c 'select count(*) from restaurants'
   ```
3. 0건이면 테이블과 enum 을 지운다. 데이터가 있으면 지우지 말고 맥북에서 대화를 이어서 방법을 정한다.
   ```bash
   docker exec food-map-postgres psql -U foodmap -d foodmap -c 'begin; drop table restaurant_business_hours; drop table restaurants; drop type restaurant_cuisine; drop type restaurant_category; commit;'
   ```

## 6. 마이그레이션 적용

```bash
pnpm --filter @food-map/api db:migrate
```

- `migrations applied successfully!` 가 나오면 된다.
- 접속 주소는 `apps/api/drizzle.config.ts` 기본값(`postgres://foodmap:foodmap@localhost:5432/foodmap`)을 쓴다. `.env.dev` 의 `DATABASE_URL` 과 같다.

## 7. 적용 확인

```bash
docker exec food-map-postgres psql -U foodmap -d foodmap -c 'select name from drizzle.__drizzle_migrations'
```

- `20260930104547_init` 한 줄이 나오면 맥북 DB 와 같은 상태다.

## 참고

- 좌표 조회 API(`0ce4b48`)와 supertest e2e 테스트도 이번 pull 에 들어 있다. `pnpm --filter @food-map/api test` 로 확인할 수 있고 DB 없이 실행된다.
- 앞으로 스키마를 바꾸면 `pnpm --filter @food-map/api db:generate` 로 마이그레이션 파일을 만들어 커밋한다. 다른 기기는 pull 후 `db:migrate` 를 실행한다. `db:push` 는 쓰지 않는다.
