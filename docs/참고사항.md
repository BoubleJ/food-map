# 참고사항

## admin 인증

- admin API 인증 로직을 추가해야 한다
- `infra/caddy/Caddyfile` 이 `{$DOMAIN}/api/*` 와 `api.{$DOMAIN}` 도 api 로 연결해서, 사용자용 도메인에서도 `/api/admin/*` 를 호출할 수 있다

## 에러 처리

- [neverthrow](https://github.com/supermacro/neverthrow) 를 쓰면 예외를 던지지 않고 `Result` 값으로 함수형 에러 처리를 할 수 있다
- NestJS, oRPC 와 함께 쓰는 사례: [teable](https://github.com/teableio/teable), [modular-monolith-starter](https://github.com/ihssmaheel-dev/modular-monolith-starter), [hazard-pay](https://github.com/arnavp103/hazard-pay)(oRPC 만)
