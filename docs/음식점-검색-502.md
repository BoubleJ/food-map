# 음식점 검색 502

2026-10-01 `GET /api/admin/restaurant-search` 가 가끔 502(`주소 좌표 조회에 실패했습니다.`)로 응답했다.

## 원인

- 도로명주소 좌표 API(`addrCoordApi.do`)가 짧은 시간에 호출이 몰리면 `E0007`(짧은 시간동안 다량의 주소검색 요청)을 돌려준다.
- 음식점 검색은 카카오 결과(최대 15건)마다 좌표 API 를 `Promise.all` 로 동시에 호출한다.
- `JUSO_ERROR_STATUS` 에 `E0007` 이 없어서 502 로 바뀌고, 한 곳만 실패해도 검색 전체가 실패한다.

## 측정값

- 간격 없이 연속 호출하면 11번 성공하고 12번째에 `E0007`
- 500ms 간격이면 30번 모두 성공
- `E0007` 은 약 0.5초 뒤 풀린다
- 주소 검색 API(`addrLinkApi.do`)는 30번 연속 호출해도 제한이 없었다

## 수정 방향

- 검색에서는 좌표를 조회하지 않고, 저장 API(`POST /api/admin/restaurants`)에서 저장할 식당만 조회한다
- 한 번에 최대 10개까지 저장하고, 좌표는 순서대로 조회한다
- `E0007` 이면 0.5초 뒤 다시 시도하고, 계속 실패하면 503 으로 응답한다
- 카카오 응답은 장소 id, url, 이름만 저장할 수 있어서 좌표는 도로명주소 API 에서 받는다
