# 맥북 작업

우분투에서 로컬 DB 를 쓰지 않고 개발 서버 DB 에 SSH 터널로 접속하도록 바꿨다. 맥북도 같은 구성으로 맞춘다. 명령은 저장소 루트(`food-map/`)에서 실행한다.

## 1. pull 전에 .env.local 만들기

pull 하면 git 에 커밋되어 있던 `.env.dev` 가 지워진다. pull 하기 전에 `.env.dev` 와 `.env` 를 합쳐 `.env.local` 을 만든다.

```bash
cat .env.dev .env > .env.local
chmod 600 .env.local
```

`.env.local` 에서 아래를 고친다.

- `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` 세 줄을 지운다.
- `DATABASE_URL` 을 개발 서버 주소로 바꾼다. 비밀번호는 우분투의 `.env.local` 과 같다.
  ```
  DATABASE_URL=postgres://foodmap:<개발 서버 DB 비밀번호>@localhost:15432/foodmap
  ```

## 2. pull, 의존성 설치

```bash
git pull
pnpm install
```

## 3. 로컬 postgres 정지

`db:down` 스크립트는 지웠다. 컨테이너를 직접 멈춘다.

```bash
docker stop food-map-postgres
```

## 4. SSH 설정

1. Lightsail 콘솔에서 기본 키(`LightsailDefaultKey-ap-northeast-2.pem`)를 받아 `~/.ssh/` 에 두고 권한을 준다.
   ```bash
   chmod 600 ~/.ssh/LightsailDefaultKey-ap-northeast-2.pem
   ```
2. `~/.ssh/config` 에 아래를 추가한다. `HostName` 은 Lightsail 콘솔에서 개발 서버 IP 를 확인해 넣는다.
   ```
   Host foodmap-dev
     HostName <개발 서버 IP>
     User ubuntu
     IdentityFile ~/.ssh/LightsailDefaultKey-ap-northeast-2.pem
     LocalForward 15432 127.0.0.1:5432
   ```

## 5. 접속 확인

터미널 하나에서 터널을 열고, 다른 터미널에서 마이그레이션을 실행한다.

```bash
pnpm db:tunnel
pnpm --filter @food-map/api db:migrate
```

마이그레이션은 우분투에서 적용했으므로 적용할 것이 없다고 끝나면 된다. 그다음 api 개발서버를 띄워 정상적으로 시작되는지 확인한다.

## 6. 확인할 것

- 이전에 맥북에서 Lightsail 에 SSH 로 접속한 서버가 개발 서버와 같은 서버인지 `~/.ssh/known_hosts` 나 터미널 기록에서 확인한다.
- 이전에 맥북에서 `docker compose` 로 띄운 컨테이너가 맥북에 남아 있는지 `docker ps -a` 로 확인한다.
